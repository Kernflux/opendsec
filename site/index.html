给每一次 rollout 一个隔离的 sandbox An isolated sandbox for every rollout

OpenDsec 在你自己的机器上运行大批 Firecracker microVM、容器和 QEMU 虚拟机，供强化学习训练和会执行代码的智能体使用。它照 DeepSeek 的 DSec 论文实现，兼容 E2B 的 SDK。 OpenDsec runs large fleets of Firecracker microVMs, containers and QEMU VMs on your own machines, for reinforcement-learning rollouts and code-executing agents. It implements the design in DeepSeek's DSec paper and speaks the E2B API.

功能Features

为强化学习训练设计Built for RL training

标注「论文」的来自 DSec 论文的设计；标注「新增」的是我们自己的选择。docs/SPEC.md 逐条注明了出处。"Paper" marks a design taken from the DSec paper; "Added" marks our own choices. docs/SPEC.md cites the source of each one.

四种后端Four backends

容器、FnCall、Firecracker microVM、QEMU 完整 VM（支持 PCI 直通）。同一套 API 和 SDK。Container, FnCall, Firecracker microVM and QEMU full VM with PCI passthrough, behind one API and SDK.

论文 · microVM 为主力：新增Paper · microVM as the main backend: added

fork 与内存快照Fork and memory snapshots

fork(count=N) 连同内存复制正在运行的 VM。同节点副本共享内存页，跨节点直接从源节点拉取。fork(count=N) clones a running VM with its memory. Copies on one node share pages; other nodes pull from the source node.

新增Added

按任务暂停Pause a whole task

训练被抢占时整批暂停，内存换出或释放；之后对暂停的 sandbox 发请求会自动恢复。Pause every sandbox of a task when training is preempted, releasing memory. The next call to a paused sandbox resumes it.

论文Paper

分层镜像Layered images

从任意 OCI 仓库导入，组合镜像不复制数据，pack_diff 把环境存成新镜像。镜像库放在 NFS、CephFS 或 JuiceFS 上。Import from any OCI registry, compose layers without copying, and save an environment with pack_diff. The store lives on NFS, CephFS or JuiceFS.

论文 · 共享文件系统：新增Paper · shared file system: added

默认拒绝的网络Default-deny network

每个 sandbox 按域名、网段和端口放行，运行中可以修改。由 nftables 和 DNS 代理执行。Allow by domain, CIDR and port per sandbox, changeable while it runs. Enforced with nftables and a DNS proxy.

论文 · nftables 实现：新增Paper · nftables enforcement: added

隔离Isolation

每个 VM 独立 uid 的 jailer、防 SMT 侧信道的核心调度、seccomp、只读代理、按会话的用户。A jailer with a uid per VM, core scheduling against SMT side channels, seccomp, read-only agents, per-session users.

论文Paper

项目与配额Projects and quotas

多级项目、层级配额、有界委托；IAM 用 Raft 多副本；组件之间 mTLS，短期可吊销的 token，审计日志。Nested projects, hierarchical quotas, bounded delegation. Raft-replicated IAM, mTLS between components, short-lived revocable tokens, audit logs.

论文Paper

兼容 E2BE2B compatible

按 E2B SDK 写的程序不改代码就能运行：命令、文件、PTY、端口、fork、快照、code interpreter。官方 Python 和 JS SDK 的验收检查全部通过。Programs written for the E2B SDK run unchanged: commands, files, PTY, ports, fork, snapshots, code interpreter. E2B's Python and JS SDK checks all pass.

新增Added

运维Operations

fleet 分批滚动升级，失败自动回退；离线安装包；Prometheus 指标和告警。升级任何组件都不影响运行中的 sandbox。Staged fleet rollouts with automatic rollback, an offline bundle, Prometheus metrics and alerts. Upgrading any component leaves running sandboxes alone.

新增Added

架构Architecture

无状态入口，节点做最终准入A stateless front door; each node admits its own work

apiserver 按 watcher 汇总的状态用 power-of-k 选节点，节点上的 edge 根据实际资源决定接不接。任何一个组件重启，运行中的 sandbox 都不受影响。The apiserver picks nodes with power-of-k over the state the watcher aggregates, and the edge on each node decides from real usage. Any component can restart without touching running sandboxes.

快速开始Get started

一台 Linux 机器，几分钟装好One Linux machine, a few minutes

需要 x86_64、root、systemd、cgroup v2，以及 Go 1.27+ 和 make。有 /dev/kvm 时同时装好 microVM，没有就只装容器。已在全新的 Ubuntu 24.04 上验证。Needs x86_64, root, systemd, cgroup v2, Go 1.27+ and make. With /dev/kvm you get microVMs too; without it, containers only. Verified on fresh Ubuntu 24.04.

1

取代码并安装。脚本会下载 guest 内核，装好全部服务和 E2B 网关，并各跑一个容器和 microVM 做检查。Clone and install. The script downloads the guest kernel, installs every service and the E2B gateway, then runs one container and one microVM as a check.

git clone https://github.com/kernflux/opendsec
cd opendsec
sudo deploy/quickstart.sh
2

装 Python SDK，运行示例。Install the Python SDK and run the example.

. /root/opendsec-ops/demo.env
python3 -m venv .venv
.venv/bin/pip install ./sdk/python
.venv/bin/python sdk/python/examples/quickstart.py
3

不用了就卸载，机器恢复原样。Remove everything when you are done.

sudo deploy/quickstart.sh --uninstall
from opendsec import DSecClient, DSecContainerRunArgs

async with DSecClient() as client:
    sb = await client.run_container(DSecContainerRunArgs(
        container_image="root/py:3.12",
        memory_limit_mb=4096, cpu_cores_limit=4,
        network_rules={"pypi": True}, task_id="job-1"))
    r = await sb.run_shell("pip install pytest && pytest -q")

    forks = await sb.fork(count=8)   # 8 copies of this exact state
    await client.pause_task("job-1")  # preempted: pause the batch
# point the E2B SDK at your gateway; nothing else changes
export E2B_API_URL=http://gateway:7400
export E2B_SANDBOX_URL=http://gateway:7400
export E2B_API_KEY=<OpenDsec token>

from e2b import Sandbox

sbx = Sandbox.create()
print(sbx.commands.run("uname -r").stdout)
snap = sbx.create_snapshot()        # microVM: memory included
copy = Sandbox.create(snap.snapshot_id)
# import an image into the shared store
opendsecctl image import docker://python:3.12-slim \
    -as root/rl/python:3.12 -store /mnt/opendsec-images

# 500 sandboxes for one task, then pause them together
opendsecctl sandbox create -backend microvm \
    -image root/rl/python:3.12 -count 500 -task job-1
opendsecctl task pause job-1

opendsecctl exec "$ID" python3 -c 'print(6*7)'
